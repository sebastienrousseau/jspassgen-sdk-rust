# Support

## Supported versions

| Version | Status | Fixes |
| :--- | :--- | :--- |
| `0.0.23` | Latest release | Yes |
| `0.0.22` | Previous release | No |

Versions move in `0.0.1` steps, in lockstep with the jspassgen suite;
the latest release receives fixes, and an older one is fixed by
upgrading.

## Getting help

- Usage questions and bugs: open an issue in this repository with the
  crate version or commit, `rustc --version` and a minimal reproducer.
  Never paste a password you use.
- A problem in the generators' rules themselves: [jspassgen issues](https://github.com/sebastienrousseau/jspassgen/issues).
- Security reports: never in an issue; see [SECURITY.md](https://github.com/sebastienrousseau/jspassgen-sdk-rust/blob/main/SECURITY.md).

The project is maintained in a personal capacity, with no SLA.
